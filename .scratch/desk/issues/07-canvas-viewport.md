# 07: Canvas viewport — pan, zoom, home, overview

**What to build:** The desk becomes an infinite canvas the user can move around
in without ever getting lost.

**Blocked by:** 05

**Status:** ready-for-agent

- [x] The user can pan the desk in any direction, with no bounds
- [x] The user can zoom in and out smoothly
- [x] The `0` key snaps the viewport back home
- [x] A zoomed-out overview shows everything on the desk at once, so a sheet placed long ago can be found
- [x] The viewport position persists across reload
- [x] Panning and zooming never alter any sheet's position or size in desk coordinates
