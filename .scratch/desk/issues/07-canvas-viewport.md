# 07: Canvas viewport — pan, zoom, home, overview

**What to build:** The desk becomes an infinite canvas the user can move around
in without ever getting lost.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] The user can pan the desk in any direction, with no bounds
- [ ] The user can zoom in and out smoothly
- [ ] The `0` key snaps the viewport back home
- [ ] A zoomed-out overview shows everything on the desk at once, so a sheet placed long ago can be found
- [ ] The viewport position persists across reload
- [ ] Panning and zooming never alter any sheet's position or size in desk coordinates
